# Code4hood-org-website
Code4Hood website source and maintenance repo.

## Overview
This repository contains the HTML, CSS, JavaScript, images, and other assets used to maintain the Code4Hood website.

## Tech Stack
- HTML
- CSS
- JavaScript
- Bootstrap
- Static assets

## Deployment
This site is hosted on SiteGround and deployed manually via FTP.

## Workflow
1. Download/update files from SiteGround
2. Make changes locally
3. Preview changes with a local server
4. Commit changes to Git
5. Push updates to GitHub
6. Upload approved files to SiteGround via FTP

## Notes
- Changes should be tested locally before deployment
- Only approved changes should be uploaded to production
